# Ladestopp

Ziel eingeben, Ladesäulen entlang der Route nach Anbieter, Stecker und Leistung filtern und mit Google Maps oder Apple Karten losfahren.

**App:** https://kaplaniket.github.io/ladestopp/

- Ladesäulen: Ladesäulenregister der Bundesnetzagentur (Deutschland), außerhalb OpenStreetMap
- Karte und Orte: OpenStreetMap, Route: OSRM
- Die App liegt im Branch `gh-pages`. Die Daten werden monatlich per GitHub Action aktualisiert.
